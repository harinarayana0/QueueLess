# QueueLess

A web-based virtual queue and appointment management system
built with Python and Flask.

## Overview

QueueLess helps customers join service queues digitally and
book appointments. Administrators manage service availability
and ticket progression.

## Project status

Project documentation is included in this repository.
See the application files and testing evidence for the
current implementation status.

## Technology stack

- Python and Flask
- Flask-Login
- Flask-SQLAlchemy and SQLAlchemy
- HTML, CSS, and JavaScript
- SQLite for local use
- PostgreSQL for containerised deployment
- Docker Compose
- pytest
